#Rudder_Infantry_Gimbal 
## 硬件平台
单片机：RoboMaster C型开发板（STM32F407）

陀螺仪：BMI088

云台电机：GM6020*2

摩擦轮电机：3508转子*2

拨盘电机：DM4310*1

## 工具链
本工程主要参考湖南大学跃鹿战队嵌入式工程开源，使用 CubeMX+CMake+GCC+OpenOCD工具链，使用 vscode作为IDE开发
文件目录说明
该工程主要使用C++语言，基于面向对象思想进行设计，实现了集成化和模块化，便于后续Debug和开发。代码主要构建在user文件夹当中，代码层次如下：
```
└─ user
       ├─ algorithm      # 需要用到的算法
       ├─ application    # 顶层任务设计，包含相关任务函数
       ├─ bsp            # 对HAL库函数进行封装
       └─ modules        # 相关外设驱动
```

## 烧录
VS Code 中运行 `DapLink Download` 任务会先构建 Debug 固件，再通过 OpenOCD 烧录 `build/Debug/EC_C_Board.elf`、校验并复位目标板。OpenOCD 的 CMSIS-DAP、STM32F4 目标和 1 MHz SWD 时钟统一配置在 `openocd.cfg`。

若连接或烧录仍不稳定，请检查目标板供电、SWDIO/SWCLK/GND 接线和探针连接，并确认没有其他 OpenOCD/J-Link 会话占用调试器。

## 代码逻辑
任务：  
`defaultTask`               # 以10Hz频率闪灯，标记启动状态  
`INS_Task`                  # 陀螺仪任务，使用东北大学AHRS  
`GimbalTask`                # 云台控制，发射机构控制，底盘速度控制  
`ModeTask`                  # 根据遥控器设置整车状态  
`ChassisTask`               # 与底盘的板间通信，控制底盘状态  
`CanTask`                   # 发送CAN消息控制Pitch,Yaw轴，以及发弹机构  

## 控制逻辑
底盘模式(非急停均可手动控制云台)
 | 左S1上S2 | 上                | 中                    | 下       |
 | -------- | ----------------- | --------------------- | -------- |
 | **上**   | 摩擦轮(连发)+陀螺 | 摩擦轮(连发)+底盘跟随 | 角向跟随 |
 | **中**   | 摩擦轮(单发)+陀螺 | 摩擦轮(单发)+底盘跟随 | 角向跟随 |
 | **下**   | 陀螺              | 底盘跟随              | 急停     |

自瞄模式
 | 左S1上S2 | 上                        | 中                    | 下                    |
 | -------- | ------------------------- | --------------------- | --------------------- |
 | **上**   | 摩擦轮(自瞄火控)+自瞄云台 | 摩擦轮(连发)+手动云台 | 摩擦轮(连发)+手动云台 |
 | **中**   | 摩擦轮(手动)+自瞄云台     | 摩擦轮(手动)          | 摩擦轮(手动)          |
 | **下**   | 自瞄云台                  | 手动云台              | 急停                  |

 | 切换尖角/正常模式 | Ctrl               |

 | 连发              | 鼠标左键长按       | 4 |
